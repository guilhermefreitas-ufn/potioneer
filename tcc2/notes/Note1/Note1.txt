CALDEIRÃO
   ↓
1. LIMPEZA
   ↓
remove slots vazios
   ↓
2. TOKENIZAÇÃO
   ↓
ingredientes → tokens
   ↓
3. INTERPRETADOR
   ↓
tokens → estruturas
   ↓
4. VALIDAÇÃO
   ↓
sintaxe + semântica
   ↓
5. EXECUÇÃO
   ↓
poção pronta e funcional

EXEMPLO:
Caldeirão:

[if][ ][hp][ ]
[ ][enemy][greater][ ]
[int][hp][enemy][ ]
[decreases][int][ ]

ETAPA 1
Remove vazios:
[if][hp][enemy][greater][int][hp][enemy][descreases][int]

ETAPA 2
Transforma em tokens:
CONDICIONAL
VARIAVEL(hp + enemy)
OPERADOR_COMPARACAO(greater)
PRIMITIVO(int)
VARIAVEL(hp + enemy)
OPERADOR_EFEITO(decreases)
PRIMITIVO(int)

ETAPA 3
O interpretador reconhece:
ALGORITMO
├── CONDICIONAL
│    └── if
│ 
├── CONDIÇÃO
│    ├── VARIAVEL
│    │   ├── value = hp
│    │   └── target = enemy
│    │
│    ├── OPERADOR = greater
│    │
│    └── VALOR = int
│
└── EFEITO
     ├── VARIAVEL
     │   ├── value = hp
     │   └── target = enemy
     │
     ├── OPERADOR = decreases
     │
     └── VALOR = int

ETAPA 4
Verifica Sintaxe e Semântica:
if → correto
enemy.life → correto
greater → correto
int → correto
decreases → correto

ETAPA 5
Criação de uma poção válida e funcional.
